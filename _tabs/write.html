点下面的大按钮，会在新标签页打开 GitHub 的新建文件页面，文件名、日期和日记模板都已经填好，直接写正文就行。

{{ today }}- .md
文件名只能用英文、数字和短横线（例如 java-threads），不填就是 diary。同一天写第二篇时记得换一个。 多个标签用逗号隔开，例如 日记, python。
开始写今天的日记

将创建：_posts/{{ today }}-diary.md

怎么用

  1. 点上面的按钮（需要先在浏览器里登录 GitHub）。
  2. 在打开的页面里把每个小标题下面的内容写完，用不上的小标题可以删掉。
  3. 写完点右上角绿色的 Commit changes，再点一次确认。
  4. 一两分钟后自动上线。可以在 Actions 页面 看进度，出现绿色对勾就好了。

想改已经发布的日记：打开那篇文章，点文章底部的“编辑”链接。
